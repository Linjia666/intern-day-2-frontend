# Intern Day 2 · Frontend

React + TypeScript 待办清单前端。配套后端仓库：<替换为 backend GitHub 地址>

## 功能范围
- 项目主题：待办清单小工具
- 登录流程：登录页 → 后端校验 → 功能页显示当前用户 → 新增/勾选/删除待办 → 退出登录
- 自选功能：待办清单（新增、勾选完成、删除）

## 验收条件
1. 错误密码提示"账号或密码错误"，空值被前端校验拦截
2. 未登录访问功能页回到登录页；不带、伪造或过期 token 调接口返回 401
3. 退出后旧 token 调接口返回 401
4. 登录后可新增、勾选、删除待办，数据来自后端受保护接口
5. 刷新页面：token 在有效期内保持登录并重新校验（调 /auth/me），失效则回登录页
